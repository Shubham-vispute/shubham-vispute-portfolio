# Shubham Kishor Vispute — Personal Technical Portfolio

A responsive static website built with HTML, CSS and vanilla JavaScript. It is designed for free hosting on GitHub Pages.

## Included

- `index.html` — portfolio home page and sections for profile, skills, career, projects, learning hub, videos, resume and contact.
- `styles.css` — dark navy/cyan responsive design.
- `script.js` — mobile navigation, project filters and resume print action.
- `resume.html` / `resume.css` — print-friendly resume page; use the browser's **Print → Save as PDF**.

## Preview locally

No build tools are required.

- Extract the ZIP.
- Open `index.html` in a modern browser.

For a local web server (optional), run from the extracted folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish on GitHub Pages (free)

1. Sign in to GitHub and create a **public** repository named `shubham-vispute-portfolio` (or another name you prefer).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside another nested folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. GitHub will show the published URL in the Pages settings. A project site URL normally looks like `https://YOUR-USERNAME.github.io/shubham-vispute-portfolio/`.
7. Test the site on desktop and mobile, including all navigation links and the resume print action.

GitHub's interface can change. Follow the current official guide if labels differ: https://docs.github.com/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Updating the website

Edit the HTML and CSS files, commit/push the changes, and GitHub Pages will redeploy. Keep paths relative (for example `styles.css` and `articles/yocto-guide.html`) so project-site URLs work.

## Privacy and security

A public GitHub Pages website is visible to anyone. Do not publish home address, private phone number, confidential customer details, internal source code, proprietary diagrams or employer-only information. Use only material you are authorized to share.
